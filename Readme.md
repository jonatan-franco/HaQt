# **O que é o HaQt**

_Hábito Quantum_ é uma plataforma que te auxilia a monitorar seus hábitos focados em saúde (sono, exercícios físicos, etc) e estudos (leitura, resolução de exercícios e mais). 

# Como funciona?
A aplicaçào vai utilizar seus dados para construir uma métrica de consistência olhando para a média e desvio-padrão de horas dedicadas a tais e quais atividades. Também construirá a métrica de **engajamento** com a função de **elasticiddade**.
